# Code of conduct

## Our standards

We want the rssnook community to be welcoming, practical, and safe. Participants are expected to:

- communicate with empathy and respect;
- critique ideas and code without attacking people;
- welcome questions and different levels of experience;
- accept constructive feedback and take responsibility for mistakes;
- avoid harassment, discrimination, sexualized attention, threats, and the disclosure of private information.

## Scope

This code applies in repository issues, pull requests, reviews, discussions, and other spaces where someone is representing the rssnook community.

## Enforcement

Repository maintainers may edit or remove contributions that violate these standards and may temporarily or permanently restrict participation. Report conduct concerns privately through the repository owner's contact options on GitHub. Reports will be reviewed promptly and handled as confidentially as practical.

## Attribution
